# บทคัดย่อ

โครงงานนี้พัฒนาระบบ Order CSV Quality Monitor สำหรับตรวจสอบคุณภาพไฟล์ CSV คำสั่งซื้อในด้านความครบถ้วน ความไม่ซ้ำ และความถูกต้องของค่า โดยกฎกำหนดในไฟล์ YAML ไฟล์ที่ไม่ใช่ข้อมูลคำสั่งซื้อจะถูกทำโปรไฟล์และตรวจด้วยกฎที่สร้างอัตโนมัติจากเนื้อหา ระบบตัดสินผล PASS / WARN / FAIL บันทึกประวัติลง SQLite และแสดงแนวโน้ม Pass Rate บนเว็บที่พัฒนาด้วย Streamlit

ผลการทดสอบพบว่าผ่านการทดสอบหน่วย 19 รายการ ได้ F1 = 1.000 บนชุดมาตรฐาน 200 แถว และ F1 = 0.500 บนชุดกรณียาก 45 แถว ซึ่งมาจากการนิยามเฉลยของแถวว่าง ไม่ใช่ความผิดพลาดของกฎ

**คำสำคัญ:** คุณภาพข้อมูล, การตรวจสอบไฟล์ CSV, Streamlit, การตรวจสอบตามกฎ
